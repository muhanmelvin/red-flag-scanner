    How this is built

    The page contains no audit arithmetic of its own. Every flag, every dollar figure and every line of working comes from scan() — a pure TypeScript function compiled straight into this page, the same function a test suite pins to the cent against hand-computed fixtures and against three synthetic reconciliation packages with planted findings. Deterministic: same input, same output, every time.

    There is no AI in the arithmetic. A language model can draft prose; it should never decide whether a cap was breached or by how much. The roadmap's narrative layer will write from engine output, never compute numbers.

    The three packages are synthetic, written for teaching and demonstration: the fictional Maplewood Commerce Center and its fictional tenants. No client lease, statement or figure appears anywhere in this page — two automated gates refuse to ship if one does. Uploads are parsed in your browser with SheetJS and scanned here; the page's security policy forbids it from opening any network connection at all.
